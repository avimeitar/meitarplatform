# Meitar Platform

מערכת CRM ושיווק עצמאית לקבוצת מיתר, שמחליפה את פיירברי. לידים, שיחות, וואטסאפ, פגישות, עסקאות, דפי נחיתה וקמפיינים, במקום אחד.

- **הפעלה ב-Railway והתחברות ראשונה**: [docs/SETUP.md](docs/SETUP.md)
- **מפרט מפורט לפיתוח**: [docs/SPEC.md](docs/SPEC.md). הסיכום הקצר למנהלים נמצא במסמך "מערכת מיתר החדשה".
- **הדמיית העיצוב שאושרה**: [docs/design/preview.html](docs/design/preview.html)
- **נכסי מיתוג**: [brand/](brand/)

## מה כבר עובד (שלב 1)

- כניסה עם טלפון וסיסמה, ואחריהם קוד ב-SMS או בוואטסאפ. שכחתי סיסמה, קישורי הזמנה, "לזכור את המכשיר".
- משתמשים, תפקידים והרשאות: הוספה, עריכה, השבתה ומחיקה עם העברת לידים. יומן פעולות.
- לידים: רשימה עם תצוגות וחיפוש, כרטיס ליד, ליד חדש עם זיהוי כפילויות לפי טלפון, שיוך וחלוקה אוטומטית.
- תור שיחות לסוכן, ואחרי כל שיחה "מה קרה?" עם ארבע תשובות. ביטול לכל פעולה.
- פגישות עם סטטוסים (תואמה, בוטלה, התקיימה) שמעדכנים את הליד, ומשימות.
- דשבורד לסוכן ודשבורד למנהל: לידים מהלילה, התראות, המסלול ומשימות הצוות.
- וואטסאפ בשלב 1: ההודעה נפתחת בוואטסאפ של הסוכן ונרשמת בכרטיס. שליחה אוטומטית ותיבת שיחות מגיעות בשלב 2.
