# Meitar Platform

מערכת CRM ושיווק עצמאית לקבוצת מיתר, שמחליפה את פיירברי. לידים, שיחות, וואטסאפ, פגישות, עסקאות, דפי נחיתה וקמפיינים, במקום אחד.

- **מפרט מפורט לפיתוח**: [docs/SPEC.md](docs/SPEC.md). הסיכום הקצר למנהלים נמצא במסמך "מערכת מיתר החדשה".
- **הדמיית עיצוב לחיצה**: [docs/design/preview.html](docs/design/preview.html). פותחים את הקובץ בדפדפן. כל הנתונים בהדמיה לדוגמה.
- **נכסי מיתוג**: [brand/](brand/). לוגו בכחול, בנייבי, בשחור ובלבן, וסמל ה-M בנפרד.

**סטטוס**: שלב תכנון, ממתין לאישור.
